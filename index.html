USAGE NOTES

三个 AI Agent 的使用情况

对 WorkBuddy、Trae、Codex 三款 AI 编程助手在日常使用中的表现做一份平实的记录：各自适合什么、还差什么，尽量不下绝对结论。

整理时间：2026 年 10 月 · 语气仅供参考，具体体验因项目而异

一、WorkBuddy

定位偏「通用桌面助理 + 编程协作」，长处在于任务编排与本地环境整合。

W

WorkBuddy

腾讯系 AI 助手 · 桌面端 / 面板式交互
任务规划多文件读写 定时任务连接器生态可视化输出
维度使用情况
上手难度较低。对话即任务，不需要额外配置开发环境；对非纯编程用户比较友好。
代码能力能满足常规脚本、网页、小型工具的开发；复杂工程的重构建议偶有保守，需要人来把关。
上下文管理有会话记忆与工作区记忆机制，跨天继续任务时能接上此前约定，但偶尔需要手动提醒细节。
突出点可调用大量第三方连接器（文档、表格、知识库等），也能排定时任务；把「写代码」和「办公杂务」放进同一个工作流是它的差异点。
不足之处连接器质量参差，个别服务授权流程繁琐；纯 CLI 重度开发者可能会觉得交互不够轻量。
小结：适合把编程当作手段而非目的的用户——写个工具、做个页面、顺带整理资料，一条流水线做完。对硬核工程化需求，当作「项目经理 + 初级开发」的组合来用比较合理。

二、Trae

AI 原生 IDE，主线体验是「边写边改」的即时协作，中文生态适配较好。

T

Trae

字节跳动 · AI IDE（基于 VS Code 生态）
AI IDEBuilder 模式 实时预览中文界面前端友好
维度使用情况
上手难度低。界面接近 VS Code，老用户几乎零迁移成本；内置模型开箱即用。
代码能力前端页面与小中型项目生成速度可观，Builder 模式可以按需求批量建文件；大型项目中跨文件理解偶尔会漏掉隐含约定。
协作体验内置实时预览对调样式很省事；对话与编辑器联动，改哪一段可以直接看到 diff。
突出点中文场景（注释、需求描述、报错解读）理解自然；免费额度对轻度使用者够用，产品迭代速度较快。
不足之处生态还在成长期，部分 VS Code 插件兼容性需逐个验证；深度自定义（如 agent 编排）不如老牌方案灵活。
小结：个人开发者做前端、做原型的效率工具，中文体验是目前几款里比较顺的。把它当主力 IDE 用没问题，但复杂项目仍建议配好版本管理，方便随时回滚。

三、Codex

OpenAI 出品的编程智能体，命令行与云端任务并行，风格克制、改动可控。

C

Codex

OpenAI · CLI / IDE 扩展 / 云端沙箱任务
CLI 优先沙箱执行 批量任务代码审查自主度高
维度使用情况
上手难度中等。对习惯终端的用户很顺手；纯 GUI 用户需要一点适应期。
代码能力单文件与多文件的常规改动稳定；在明确边界（有 README、有测试）的仓库里自主完成度较高，改动前会先说明计划。
执行方式本地命令行交互 + 云端并行任务双轨。可以同时派出多个任务在沙箱里跑，完成后回来审 diff，适合「批量杂活」。
突出点输出风格克制，不擅自大改；对「先读懂仓库再动手」这类要求执行得比较认真。
不足之处对网络环境有要求；中文自然语言交互不如国产工具顺手；复杂任务的中间过程有时需要人工纠偏。
小结：适合有一定工程习惯的开发者，尤其是喜欢用终端、按 diff 审代码的人。它的价值不在「写得最快」，而在「改得让人放心」。
知

实际案例：知页 —— 一个本地书籍知识平台

使用 Codex 辅助开发的个人知识平台项目（完整源码见 zhiyue-source.md）

「知页」是在 Codex 协助下完成的一个本机运行的书籍知识平台：它把整本书按页组织成可检索的知识库，让阅读笔记从散落的摘录变成可以探索的知识网络。项目整体规模不大，但结构完整——前端、后端、启动脚本一应俱全，一定程度上体现了 Codex 在「边界清晰的小型全栈项目」上的可用性。

按页组织的书库支持导入 PDF / TXT / Markdown，保留原始页码，形成「我的书库」。
定向检索可按概念、问题或指定页码搜索全书，结果附带页码定位。
知识网络自动提取书中高频概念并生成共现关系图，点击节点回到原文。
基于原文的对话接入 DeepSeek，回答严格引用书中内容并附页码，材料不足时明确说明。
隐私优先书籍文件本地解析、不上传，API Key 仅存于进程内存。
零依赖后端Python 标准库实现，双击 启动知页.bat 即可运行。

四、横向对比

三款工具侧重不同，以下对比只反映个人使用感受，不构成选型结论。

对比项WorkBuddyTraeCodex
形态桌面 AI 助手（含编程）AI IDECLI + 云端任务

交互语言中文优先中文优先英文为主

总体印象：三者并非替代关系。WorkBuddy 胜在「杂活通吃」，Trae 胜在「中文 + 前端手感」，Codex 胜在「改仓库的稳」。按任务挑工具，比押注单一工具更实际。
